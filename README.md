# 📊 Zepto Sales Performance Analysis

## 📌 Project Overview

This project analyzes Zepto sales data using Microsoft Excel to understand sales performance, product trends, revenue, discounts, and customer purchasing patterns.

The project follows the complete data analysis process from raw data cleaning to dashboard creation and business insights.

## 🎯 Project Objective

The main objectives of this project are:

- Analyze overall sales performance
- Identify top-performing products and categories
- Analyze revenue and sales trends
- Evaluate discounts and their impact on sales
- Calculate important business KPIs
- Create an interactive Excel dashboard
- Generate actionable business insights

  ## 🛠️ Tools & Skills Used

- Data Cleaning
- Excel Formulas
- Pivot Tables
- Pivot Charts
- Data Analysis
- Data Visualization
- Dashboard Creation

## 📊 Key Performance Indicators (KPIs)

The dashboard analyzes important metrics such as:

- Total Sales
- Total Revenue
- Total Orders
- Average Order Value
- Total Discount
- Product Performance
- Category Performance

## 📈 Dashboard

The cleaned Excel workbook contains the Zepto Sales Performance Dashboard with visualizations and key business metrics.

## 💡 Key Insights

The analysis helps identify:

- Best-performing products
- High-performing categories
- Sales and revenue patterns
- Discount-related trends
- Areas requiring business improvement

## 📌 Business Recommendations

Based on the analysis, businesses can:

- Focus on high-performing products
- Improve inventory availability for popular products
- Monitor discount strategies
- Identify underperforming products
- Use sales trends for better business planning
